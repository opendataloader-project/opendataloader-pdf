# Support

- **Bugs:** open an issue with the [Bug report](https://github.com/opendataloader-project/opendataloader-pdf/issues/new?template=bug_report.yml) form. Search the existing issues first.
- **Questions:** ask in [Discussions Q&A](https://github.com/opendataloader-project/opendataloader-pdf/discussions/categories/q-a).
- **Feature ideas:** post them in [Discussions Ideas](https://github.com/opendataloader-project/opendataloader-pdf/discussions/categories/ideas). The maintainers decide there on new options, defaults, output fields, and dependencies.
- **Security issues:** report them privately. See [SECURITY.md](.github/SECURITY.md).

To contribute code or documentation, see [CONTRIBUTING.md](CONTRIBUTING.md).
